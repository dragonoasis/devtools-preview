Convertisseur Docker Run to Compose

Outil en ligne gratuit pour convertir les commandes d'exécution Docker au format docker-compose.yml. Transformez instantanément les commandes de conteneur en configurations YAML composables.

Gratuit Sans inscription Fonctionne dans votre navigateur

Espace de travail de l’outil

services:
  my-app:
    image: nginx:alpine
    restart: unless-stopped
    ports:
      - "8080:80"
      - "443:443"
    volumes:
      - /data:/app/data
    environment:
      - NODE_ENV=production
      - DB_HOST=localhost

Qu’est-ce que le convertisseur Docker Run to Compose ?

Le convertisseur Docker Run to Compose est un utilitaire qui transforme les longues commandes CLI docker run en définitions de service docker-compose.yml propres et contrôlées par version. Au lieu de conserver des scripts shell difficiles à lire avec de longues commandes docker run, vous pouvez les convertir en fichiers YAML structurés plus faciles à gérer, à partager et à déployer entre les équipes.

Comment utiliser le convertisseur Docker Run to Compose

  1. 1Collez votre commande Docker Run complète dans le champ de saisie, y compris tous les indicateurs et options.
  2. 2L'outil analyse automatiquement la commande et génère la sortie équivalente docker-compose.yml.
  3. 3Examinez le YAML généré pour vérifier les ports, les volumes, les variables d'environnement et d'autres paramètres.
  4. 4Cliquez sur le bouton Copier pour copier le contenu de docker-compose.yml dans votre presse-papiers.
  5. 5Enregistrez la sortie dans un fichier docker-compose.yml dans le répertoire de votre projet.

Cas d'utilisation

Migration vers Docker Compose

Convertissez rapidement les commandes d'exécution Docker existantes de la documentation ou des scripts en fichiers docker-compose.yml pour une meilleure reproductibilité et une meilleure collaboration en équipe.

Documentation et intégration

Transformez les commandes complexes d'exécution de Docker en fichiers de composition lisibles que les nouveaux membres de l'équipe peuvent comprendre et modifier facilement.

Configuration du pipeline CI/CD

Générez des fichiers de composition à partir de commandes d'exécution Docker ad hoc utilisées pendant le développement pour créer des configurations de déploiement standardisées.

Applications multi-conteneurs

Convertissez les commandes d'exécution Docker individuelles pour chaque service en un docker-compose.yml unifié avec tous les services définis ensemble.

Questions fréquentes

Cet outil prend-il en charge tous les indicateurs d'exécution de Docker ?

L'outil prend en charge les indicateurs les plus couramment utilisés, notamment -p (ports), -v (volumes), -e (variables d'environnement), --name, --restart, --network, --hostname et --workdir. Certains indicateurs avancés peuvent ne pas être convertis automatiquement.

Quelle version de docker-compose la sortie utilise-t-elle ?

La sortie utilise le format de spécification Compose moderne (sans clé de version), qui est compatible avec Docker Compose V2 et versions ultérieures.

Puis-je convertir plusieurs commandes d’exécution Docker à la fois ?

Actuellement, l'outil convertit une commande à la fois. Pour les configurations multiservices, convertissez chaque commande docker run séparément et combinez les définitions de service en un seul fichier docker-compose.yml.

La conversion est-elle effectuée localement ou envoyée à un serveur ?

Toutes les conversions sont entièrement effectuées dans votre navigateur à l'aide de JavaScript. Aucune donnée n'est envoyée à un serveur, garantissant que vos commandes et configurations restent privées.

Confidentialité et traitement
