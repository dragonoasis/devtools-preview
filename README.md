# Souus Tools - Free Browser-Based Tools

Private-by-default utilities for development and everyday tasks.

[Live Site](https://toolbox.souus.com/) | [Feedback](https://github.com/dragonoasis/devtools-preview/issues) | [Sponsor](https://buymeacoffee.com/dragonoasis)

## What is Souus Tools?

Souus Tools is a growing collection of **free, open-source tools** for development, images, documents, text, data conversion, security, networking, calculations, and everyday tasks. Tools run locally in your browser unless a page explicitly says otherwise.

## Features

- **Private by default** - Files and input stay in the browser for tools that do not explicitly describe a network request.
- **No sign-up required** - Open a tool and use it immediately.
- **Fast and lightweight** - Static pages load quickly and support offline use where browser capabilities allow it.
- **Multi-language** - Available in several languages, with more added as they are reviewed.
- **Responsive** - Designed for desktop, mobile, and keyboard input.
- **Free and open source** - Source is available under the MIT license.
